# ADR-003. Страницы, формируемые сервером, и PWA без работы офлайн

## Контекст

- Система работает в браузере и устанавливается как PWA (НФТ-09, КП-25), интерфейс на русском (НФТ-10).
- PWA устанавливается только с сайта по доверенному HTTPS и требует манифест и service worker (Д-08).
- Основные экраны – списки и формы: каталог, заявки, очередь, выдача, возврат, отчёты. Сложных
  интерактивных экранов нет.
- Бронирование и выдача проверяются на сервере в момент действия (ФТ-12, ФТ-15, ФТ-16): выполнить их без
  связи с сервером нельзя.
- Время ответа – не более 10 секунд (НФТ-05).

## Рассмотренные варианты

1. **Страницы, формируемые сервером, + PWA** – сервер отдаёт HTML, формы отправляются обычными запросами;
   манифест и service worker только для установки и страницы «Нет связи».
2. **Одностраничное приложение (SPA, React) + REST API** – интерфейс в браузере, сервер отдаёт JSON.
3. **SPA с работой офлайн** – операции копятся на устройстве и отправляются при появлении связи.
4. **Настольное приложение** – установка на каждый компьютер.

| Критерий | 1. Сервер + PWA | 2. SPA + API | 3. SPA офлайн | 4. Настольное |
|---|---|---|---|---|
| Выполняет НФТ-09 (браузер и PWA) | Да | Да | Да | Нет |
| Объём разработки | Один код страниц и проверок | Интерфейс и API отдельно, проверки дублируются | Плюс синхронизация и разрешение конфликтов | Плюс установка и обновление на рабочих местах |
| Проверка прав и данных | На сервере, в одном месте | На сервере и в клиенте | На сервере и в клиенте | В клиенте и на сервере |
| Совместимость с ФТ-12, ФТ-16 | Да | Да | Нет: две офлайн-выдачи одной единицы конфликтуют | Да |

## Выбранное решение

Вариант 1. Страницы формирует Django (шаблоны), немного JavaScript – только для удобства (фокус в поле
серийного номера, подтверждение действий). Приложение отдаёт манифест и service worker; service worker
кеширует статические файлы и показывает страницу «Нет связи с сервером». Операции без связи не выполняются
и не копятся.

## Причины выбора

- Выполняет НФТ-09 при наименьшем объёме кода: нет отдельного API и второго набора проверок.
- Права и проверки данных – только на сервере (НФТ-01, ФТ-27, П-03, П-12).
- Офлайн-режим противоречит ФТ-12 и ФТ-16: единицу нельзя забронировать или выдать без проверки на сервере.
- Настольное приложение не выполняет НФТ-09.

## Последствия

- Каждое действие – перезагрузка страницы; для форм склада и списков это приемлемо (НФТ-05 – 10 секунд).
- Установленное PWA без сети показывает только страницу «Нет связи»; это нужно объяснить в руководстве
  пользователя.
- Если потребуется мобильное приложение или внешняя интеграция, придётся добавить API; ОГР-11 сейчас
  интеграций не предусматривает.

## Риски

| Риск | Мера |
|---|---|
| Сертификат HTTPS не доверенный – PWA не устанавливается | Сертификат выпускает заказчик (Д-08); проверка КП-25 на рабочем месте заказчика |
| Service worker отдаёт устаревшие файлы после обновления | Версия в имени кеша, старые кеши удаляются при активации нового service worker |
