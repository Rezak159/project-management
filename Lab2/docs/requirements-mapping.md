# Связь требований с архитектурными материалами

Каждое требование ТЗ ([requirements.md](requirements.md)) сопоставлено с диаграммами, компонентами, ADR и
правилами, в которых оно учтено. Сокращения:

- UC – варианты использования ([use-cases.md](use-cases.md));
- BP – бизнес-процессы ([business-processes.md](business-processes.md));
- SD – диаграммы последовательностей ([sequences.md](sequences.md));
- ER – модель данных ([data-model.md](data-model.md));
- компоненты – [architecture.md](architecture.md), раздел 2;
- П – правила ([policies.md](policies.md));
- ADR – [adr/INDEX.md](adr/INDEX.md).
