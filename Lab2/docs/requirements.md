## Переходы статусов единицы

| Переход | Условие | Кто выполняет |
| --- | --- | --- |
| в наличии → забронировано | Заявка подтверждена | Ответственное лицо |
| забронировано → в наличии | Заявка отменена или истекла | Сотрудник / система |
| забронировано → выдано | Выдача по заявке | Заведующий складом |
| выдано → в наличии | Возврат с отметкой «без повреждений» | Заведующий складом |
| выдано → починка | Возврат с отметкой «повреждена» | Заведующий складом |
| починка → в наличии | Ремонт завершён | Заведующий складом |
| в наличии, починка → списан | Единица списана | Заведующий складом |
| в наличии, выдано, починка → утерян | Единица утеряна | Заведующий складом |

Статусы заявки: «на рассмотрении», «подтверждено», «отклонено», «отменена», «истекла», «исполнена» (ФТ-09…ФТ-13, ФТ-33).
