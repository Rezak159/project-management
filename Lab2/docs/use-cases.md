# Варианты использования АС УВО

Варианты использования показаны на двух диаграммах PlantUML с общей границей системы «АС УВО»:

| Диаграмма | Исходник | Изображение |
|---|---|---|
| Заявки, выдача, возврат, сроки (UC-01…UC-10, UC-18…UC-21) | [use-cases-operations.puml](diagrams/use-cases-operations.puml) | [png](diagrams/images/use-cases-operations.png) |
| Учёт оборудования, пользователи, отчёты (UC-11…UC-17, UC-22…UC-25) | [use-cases-administration.puml](diagrams/use-cases-administration.puml) | [png](diagrams/images/use-cases-administration.png) |

На одной диаграмме 25 вариантов использования и 8 участников не читаются, поэтому разделение – по ролям:
первая диаграмма – повседневная работа сотрудников и склада, вторая – администрирование. Требования –
[requirements.md](requirements.md).

## Участники

Роли «Ответственное лицо», «Заведующий складом», «Руководитель» и «Пользователь с правом «управление
пользователями»» наследуют варианты использования роли «Сотрудник»: каждый пользователь – сотрудник
организации и может подавать заявки (ФТ-07, Д-05). «Администратор» наследует вариант использования UC-15
пользователя с правом «управление пользователями» (ФТ-05).

«Время» – запуск по расписанию для действий, которые выполняются по наступлению даты без участия
пользователя (ФТ-11, ФТ-21, ФТ-22, ФТ-24). «Почтовый сервер заказчика» – внешняя система, через которую
уходят одноразовые коды и письма (НФТ-02, ФТ-22, ВЗ-04).

Сканер штрихкодов и принтер не показаны как участники: сканер передаёт код в поле ввода браузера как
клавиатура (Д-02, ADR-004), принтер печатает страницу этикетки из браузера (Д-03). Взаимодействует с системой
заведующий складом или администратор.

## Связь вариантов использования с требованиями

| UC | Участник | Цель | Результат | Требования |
|---|---|---|---|---|
| UC-01 | Сотрудник (все роли) | Войти в систему | Вход по логину, паролю и коду из письма; после 6 неудачных попыток – блокировка на 5 минут | НФТ-02 |
| UC-02 | Сотрудник | Получить оборудование | Заявка на одну единицу «в наличии» в статусе «на рассмотрении» в общей очереди | ФТ-08, ФТ-09, ОГР-02, ОГР-10 |
| UC-03 | Сотрудник | Отказаться от заявки до выдачи | Заявка «отменена», бронь единицы снята | ФТ-33 |
| UC-04 | Сотрудник | Узнать решение по заявкам | Список своих заявок со статусами | ФТ-28 |
| UC-05 | Ответственное лицо | Взять заявку в работу | Заявка закреплена за ним, другие её не рассматривают | ФТ-09 |
| UC-06 | Ответственное лицо | Принять решение по заявке | «Подтверждено» – единица «забронировано»; «отклонено» – в том числе, если единица уже не «в наличии» | ФТ-10, ФТ-12, ОГР-04 |
| UC-07 | Заведующий складом | Выдать единицу по заявке | Единица «выдано», заявка «исполнена», записаны дата, сотрудник и заведующий; при несовпадении единицы или достижении лимита выдача не выполняется | ФТ-13, ФТ-15, ФТ-16, ФТ-17, ФТ-31, ОГР-03 |
| UC-08 | Заведующий складом | Принять единицу | Отметка «без повреждений» – «в наличии», «повреждена» с описанием – «починка» | ФТ-18, ФТ-19 |
| UC-09 | Заведующий складом | Определить единицу | Единица найдена по штрихкоду сканера или по серийному номеру, введённому вручную | ФТ-14 |
| UC-10 | Заведующий складом | Отразить ремонт, списание или утерю | Статус единицы изменён по таблице переходов | ФТ-03, ФТ-20, ОГР-12 |
| UC-11 | Администратор | Поставить единицу на учёт | Единица в каталоге со статусом «в наличии»; повтор серийного номера отклонён | ФТ-01, ФТ-02, ФТ-27 |
| UC-12 | Администратор | Получить этикетку | Этикетка со штрихкодом Code 128 напечатана, в том числе повторно из карточки единицы | ФТ-29 |
| UC-13 | Администратор | Перенести учёт из Excel | Единицы загружены, строки с ошибками и дублями – в протоколе загрузки | ФТ-30 |
| UC-14 | Администратор | Настроить систему без изменения программы | Изменены типы оборудования, сроки напоминаний, подразделения, график рабочих часов, параметры почтового ящика | ФТ-04, ФТ-22, НФТ-06 |
| UC-15 | Пользователь с правом «управление пользователями», администратор | Завести сотрудника | Учётная запись с табельным номером, ФИО, подразделением, должностью, e-mail и руководителем | ФТ-05, ОГР-09 |
| UC-16 | Администратор | Перенести список сотрудников из Excel | Учётные записи созданы, строки с ошибками – в протоколе загрузки | ФТ-06 |
| UC-17 | Администратор | Дать права и ограничить число единиц на руках | Роли и лимит сотрудника сохранены | ФТ-07, ФТ-32 |
| UC-18 | Сотрудник | Продлить срок возврата | Запрос продления с новой датой ушёл руководителю | ФТ-23 |
| UC-19 | Руководитель | Решить по запросу продления | При согласовании срок возврата изменён | ФТ-23, ОГР-07 |
| UC-20 | Руководитель | Контролировать просрочки своих сотрудников | Список просроченных выдач с длительностью просрочки | ФТ-24 |
| UC-21 | Время | Выполнить действия по наступлению даты | Не выданные заявки «истекла», просроченные выдачи отмечены, письма сотрудникам и руководителям отправлены | ФТ-11, ФТ-21, ФТ-22, ФТ-24 |
| UC-22 | Администратор | Узнать, у кого была единица | История выдачи единицы за всё время | ФТ-25 |
| UC-23 | Администратор | Получить сводные данные | Отчёт на экране и в файле .xlsx | ФТ-26 |
| UC-24 | Администратор | Проверить сотрудника, например при увольнении | Справка: взятые, возвращённые, находящиеся на руках и отправленные в починку единицы | ФТ-34, ОГР-12 |
| UC-25 | Администратор | Проверить, кто и что делал | Записи журнала за последний год | НФТ-03 |

Проверка вводимых данных (ФТ-27), разграничение доступа (НФТ-01, НФТ-04) и запись в журнал (НФТ-03)
выполняются во всех вариантах использования и на диаграмме отдельно не показаны.
